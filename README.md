# Doudizhu

`Doudizhu` 是一个运行在魔兽世界 12.x 客户端内的斗地主插件，目标是在游戏内完成 3 人联机对局，由房主负责规则校验与状态同步。

当前版本：`0.1.1`

## 当前已实现

- 3 人房间创建、加入、同步与开局流程
- 派对聊天可点击加入链接
- 房主权威的发牌、叫分、出牌、过牌与胜负判定
- 组合牌型校验与比较：
  - 单张、对子、三张
  - 三带一、三带一对
  - 顺子、连对
  - 飞机、飞机带单、飞机带对
  - 炸弹、王炸
  - 四带二、四带两对
- UI 多选手牌并提交所选牌组
- UI 展示三名玩家最近一次实际出牌
- 加入时严格校验插件版本，避免不同版本之间联机
- `/ddz local` 本地测试模式，可用两个机器人快速跑通整局

## 安装

1. 将整个 `doudizhu` 文件夹放到：
   `World of Warcraft\_retail_\Interface\AddOns\`
2. 确认目录内包含 `doudizhu.toc`、`Doudizhu.lua`、`Net.lua`、`Game.lua`、`UI.lua`
3. 启动或重载游戏，在插件列表中确认 `Doudizhu` 已启用

## 使用方法

### 快速开始

1. 房主输入 `/ddz create` 创建房间
2. 房主输入 `/ddz share` 发送可点击加入链接到队伍频道
3. 其他玩家点击聊天里的 `[Join Doudizhu]`，或手动输入 `/ddz join <房主名>`
4. 房主输入 `/ddz start` 开始一局
5. 所有人可输入 `/ddz ui` 打开界面，通过按钮完成叫分、出牌、过牌

### 本地测试

1. 输入 `/ddz local`
2. 系统会创建一局包含你和两个机器人的本地测试对局
3. 机器人会自动叫分并自动执行基础出牌逻辑，适合快速验证主要流程

## 斜杠命令

- `/ddz ui`：打开或关闭主界面
- `/ddz debug`：切换调试输出
- `/ddz create`：创建房间
- `/ddz join <host>`：加入指定房主的房间
- `/ddz share`：向队伍发送加入链接
- `/ddz start`：由房主开始对局
- `/ddz local`：启动本地机器人测试模式
- `/ddz hand`：在聊天框打印当前手牌
- `/ddz bid <0-3>`：叫分
- `/ddz play [i,j,k]`：按手牌索引出牌，也可在 UI 中多选后点击按钮
- `/ddz pass`：过牌
- `/ddz state`：打印当前状态与调试信息

## 联机说明

- 当前采用房主权威模型：客户端只提交操作意图，房主负责校验并广播状态
- 所有玩家必须使用相同插件版本；版本不一致会在加入时被拒绝
- 推荐先组满 3 人队伍，再由房主创建并分享房间，减少频道和目标选择上的歧义

## 开发与验证

常用命令：

- `git status`
- `git diff`
- `/reload`
- `/ddz ui`
- `/ddz local`
- `/ddz share`

CI：

- GitHub Actions 会在 `push` 和 `pull_request` 时自动检查仓库内所有 `*.lua` 文件的语法
- 当前语法检查基于 Lua `5.1` 的 `loadfile`，用于尽早拦截明显的语法错误

建议至少手动验证以下内容：

- 3 人创建、加入、开始流程
- 版本不一致时的拒绝路径
- 叫分与地主确定
- 组合出牌比较与连续过牌后的轮次重置
- `/ddz local` 能完整结束一局
- UI 位置在 `/reload` 后保持不变
